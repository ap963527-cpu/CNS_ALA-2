CYBERTHREAT SIMULATOR - WEB APP
================================

PROJECT CONTENTS
----------------
index.html       Main web application
css/style.css    Responsive dashboard styling
js/app.js        Simulation logic and interactions

HOW TO RUN
----------
Option 1: Simple
1. Extract CyberThreat_Simulator_Web.zip.
2. Open the CyberThreat_Simulator_Web folder.
3. Double-click index.html, or right-click and open it in Chrome or Edge.

Option 2: VS Code
1. Open the extracted folder in VS Code.
2. Install/use the Live Server extension if desired.
3. Right-click index.html and choose "Open with Live Server".

FEATURES
--------
- Virus simulation: fictional virtual-file event sequence.
- Worm simulation: fictional virtual-node propagation sequence.
- Trojan simulation: fictional deceptive-application behavior sequence.
- Start, Stop and Reset controls.
- Live activity log and session counters.
- Event distribution chart.
- Threat analysis and prevention guide.
- Responsive desktop and mobile layout.

SAFETY
------
This project is a harmless educational simulation. It does not access,
scan, create, modify or delete local files. It does not connect to a
network or other devices. It does not install software, execute payloads,
or perform persistence, credential collection or other harmful actions.
All simulation events are fictional and rendered in the browser.

INTERNET NOTE
-------------
The dashboard uses Google Fonts and Chart.js from public CDNs for fonts
and the chart. The core simulations and dashboard controls are local
JavaScript. If offline use is required, the fonts/chart may not load;
the simulations and counters will still work.
