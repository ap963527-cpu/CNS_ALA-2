Threat Analysis

Understand the typical behavior, impact and warning signs of each malware category.

✳VIRUS

Computer Virus

A virus attaches itself to a host file or program. When the infected host is run, the virus may attempt to spread to other files.

Typical impact

  • File corruption or modification
  • Loss of data availability
  • Unexpected system behavior

Warning signs

Unusual file changes, unexpected errors, or security alerts.

⌘WORM

Computer Worm

A worm is standalone malware that can spread between systems, often by exploiting vulnerabilities or weak security controls.

Typical impact

  • High network or system resource use
  • Rapid spread across connected devices
  • Service disruption

Warning signs

Unexpected network activity, slow devices, or repeated security alerts.

♢TROJAN

Trojan Horse

A Trojan disguises itself as legitimate or useful software to trick a user into installing or running it.

Typical impact

  • Unauthorized access or data exposure
  • Installation of unwanted software
  • Privacy and security compromise

Warning signs

Untrusted installers, unexpected permissions, or suspicious application behavior.

Prevention Guide

Practical security habits help reduce the risk of malware infection.

01

Keep software updated

Install operating system and application security updates promptly to reduce exposure to known vulnerabilities.

02

Use trusted downloads

Download software from official sources. Avoid unknown attachments, cracked applications and unexpected installers.

03

Use security protection

Keep reputable antivirus or endpoint protection enabled and review its security alerts.

04

Back up important data

Maintain regular backups and periodically verify that you can restore your files.

05

Use least privilege

Use a standard account for everyday work and grant permissions only when necessary.

06

Be alert to deception

Check publishers, permissions and URLs. Be cautious when software asks for unexpected access.
